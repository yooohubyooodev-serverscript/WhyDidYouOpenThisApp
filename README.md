# Why Did You Open This App?

แอปไร้สาระอย่างเป็นทางการของเรา

เวอร์ชันเริ่มต้น:
- ใช้ภาษาตามภาษาของเครื่อง
- มีภาษาไทยและอังกฤษ
- ปุ่ม "ไม่รู้"
- ปุ่ม "ออก"
- ทำงานแบบออฟไลน์

## Build

ต้องมี Android SDK และ Gradle/Gradle Wrapper ก่อน จากนั้นใช้:

    ./gradlew assembleDebug

APK จะอยู่ใน:

    app/build/outputs/apk/debug/app-debug.apk
